Reporting Architecture & Data Contract Note (CS6004ES): HealthTrack's current backend implements operational CRUD controllers (e.g., WorkoutController, DietController, AppointmentController), but does not yet contain a dedicated reporting service (e.g., ITrainerReportService) or analytical database queries. This preview specifies the required reporting schema: Client Performance, Popular Routines, and Engagement Metrics, ready for Phase 2 backend aggregation.
Report Generation Architecture Notice

Live PDF and database report generation requires the Phase 2 backend reporting pipeline and database aggregation queries.

Required Backend Contracts:
  • ITrainerReportService.GetClientPerformanceSummary(int trainerId, DateTime from, DateTime to)
  • ITrainerReportService.GetPopularRoutines(int trainerId)
  • ITrainerReportService.GetEngagementSummary(int trainerId)
