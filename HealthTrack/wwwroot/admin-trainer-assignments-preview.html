Trainer Allocation & Management

Assign dedicated certified coaches to registered clients for customized routines and guidance.

Intended MVC Route: /Admin/TrainerAssignments

Database Schema Handover: Client-to-Trainer Direct Relationship

Current Runtime State: The current Entity Framework Core schema does not contain a direct foreign key from Client to Trainer. Existing associations only exist indirectly through individual WorkoutPlan, DietPlan, and Appointment records.

Recommended Production Implementation for Backend Developer: Add a nullable int? trainerId and navigation property Trainer? trainer to Client.cs with DeleteBehavior.SetNull in HealthTrackDbContext.cs, then execute an EF Core migration.
